# Fortune Onyemuwa — Portfolio

A single-page portfolio site for Fortune Onyemuwa, product designer
specializing in Webflow and Framer.

## Structure

- `index.html` — the site
- `assets/css/style.css` — styles
- `assets/js/main.js` — mobile nav, scroll reveal, footer year
- `assets/img/portrait.jpg` — hero portrait
- `archive/` — old coursework files kept for reference, not part of the site

## Editing

All copy (bio, projects, experience, contact links) lives directly in
`index.html` — update the placeholder project names, links and social URLs
in the Work and Contact sections with real details.

Open `index.html` directly in a browser, or serve the folder locally:

```
python3 -m http.server 8000
```
